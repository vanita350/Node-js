# Admin Panel With Passport

A complete **Admin Panel** developed using **Node.js, Express.js, MongoDB, Mongoose, Passport.js, EJS**, and **Bootstrap Admin Template**. The project provides secure authentication and complete CRUD operations for Admin, Category, SubCategory, Extra Category, and Product management.

---

## 🚀 Features

### Authentication
- Admin Login
- Passport.js Authentication
- Session Management
- Protected Routes
- Logout
- Forgot Password
- OTP Verification
- Change Password
- Profile Management
